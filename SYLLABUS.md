# Programmazione assistita dall'Intelligenza Artificiale

**Docente:** Ing. Giancarlo Degani  
**Durata totale:** 16 ore (4 lezioni da 4 ore)  
**Anno accademico:** 2026/2027

Il modulo è la seconda parte di un percorso di 46 ore. Segue il corso "Elementi di programmazione e gestione dati" (30 ore), in cui gli studenti imparano il linguaggio C.

## Prerequisiti

- Il corso "Elementi di programmazione e gestione dati": saper leggere e scrivere semplici programmi in C
- CLion installato, con licenza educational
- Un account GitHub

## Programma del modulo

| Lezione | Ore | Argomenti |
| :---: | :---: | --- |
| **1** | 4 | Fondamenti: LLM, token, context window, chat e agenti; LLM in locale con LM Studio; principi del prompt |
| **2** | 4 | Prompt avanzati (CRISPE, CO-STAR, system prompt); CLion con GitHub Copilot e continue.dev; generazione di codice C |
| **3** | 4 | Debug, refactoring e test con l'AI; istruzioni di progetto (AGENTS.md, skills); uso responsabile e integrità |
| **4** | 4 | Progetto: estendere con l'AI il progetto del corso di programmazione; ripasso e verifica |

## Contenuti del modulo (Modulo 3.2)

### Introduzione alla Programmazione Assistita da AI

Definizione, vantaggi e ambiti di applicazione nel ciclo di vita del software (scrittura, modifica, comprensione, refactoring, conversione).

### Il Ruolo dell'AI come Assistente Intelligente

Esplorazione delle funzionalità principali (completamento codice, rilevamento errori, generazione da linguaggio naturale).

### L'Arte del Prompt Efficace

Principi fondamentali per la creazione di prompt chiari, specifici e ricchi di contesto per ottenere risultati ottimali dall'AI.

### Iterazione e Ottimizzazione dei Prompt

Tecniche per raffinare e adattare i prompt attraverso sperimentazione e feedback per massimizzare l'efficacia dell'AI.
